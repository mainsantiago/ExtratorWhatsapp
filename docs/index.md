# Extrator de Conversas para WhatsApp Web

Extensão do Google Chrome que exporta as conversas do WhatsApp Web, com 1 clique, para arquivos CSV e JSON no seu computador. Todo o processamento é local.

- [Política de Privacidade](./privacidade/)
- [Código-fonte e instruções](https://github.com/mainsantiago/ExtratorWhatsapp)

Esta extensão é independente e não é afiliada ao WhatsApp nem à Meta.
